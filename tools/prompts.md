# 中式梦核生图提示词模板（8h GameJam 用）

> 用法：ImageGen 等生图工具，尺寸选 **16:9**（如 1792×1024）。
> 生图命名：`normal.png`（正常画面）/ `anomaly_01.png`（异常变体），放进 `art/raw/spot_XX/`。
> **铁律：同一机位的 normal 与 anomaly 必须同构图、同视角、同光线**——只改"异常细节"。
> 异常要"一眼不对劲、又说不清哪里不对"——微妙 > 恐怖，不血腥不鬼脸直怼。

## 一、风格前缀（每条 prompt 都拼在最前面）

```
低清监控摄像头质感，1990年代中国居民区，黄昏暖黄色灯光，暗部发青，
画面有噪点和压缩伪影，轻微模糊，怀旧胶片颗粒，安静无人，诡异氛围，
写实照片风格
```

## 三、异常库（在对应机位 normal 基础上，只改一处）

拼法：`同机位的完整画面描述 + 以下改动之一`

1. 所有灯都熄灭了，只剩一点应急指示的绿色微光
2. 走廊/房间远处多了一个背对镜头、一动不动站着的人影
3. 电视屏幕的雪花里浮现一张模糊的、看不清五官的脸
4. 家具的位置和记忆里不一样了（如椅子移到了正中间，正对镜头）
5. 墙面渗出大块深色水渍，形状像一个人
6. 镜子里映出的房间和现实的布置对不上
7. 天花板上垂下一条不属于这里的红色电线，末端微微晃动
8. 窗外的居民楼全灭了灯，黑成一片
9. 挂历上的日期变成一个不存在的日子（如 2 月 30 日）
10. 门缝底下渗进一滩水，正缓缓扩大
11. 地上多出一双小孩的旧布鞋，鞋尖朝着镜头
12. 日光灯管里有一根在缓慢地忽明忽暗

## 四、批量生产节奏（8h 预算内）

1. 先一次性出 **8 张 normal**（8 个机位）→ 跑 `tools/process_art.sh` → 玩法可玩
2. 再按机位批量出 anomaly（每机位 1-2 张，先做最容易看出的）
3. 每张图出完丢 `art/raw/spot_XX/`，随时重跑降质 + Bootstrap（幂等）

## 五、已知坑（实测）

- ImageGen 会擅自改指定颜色、无真 alpha、物体计数不可靠 → 异常用"改动类"描述，不用"数出 N 个"类描述
- 生成图批次间色温会漂 → 统一靠 ffmpeg 降质参数和 URP 滤镜，不靠逐张调
- 分辨率不统一 → process_art.sh 自动归一 960×540
